# 기획 문서 안내

서비스의 방향을 정하고, 결정한 내용을 화면과 기능으로 이어가기 위한 문서 모음입니다.

## 작성 순서

1. [서비스 개요](01-service.md): 누구의 어떤 문제를 해결할지 정합니다.
2. [요구사항](02-requirements.md): 동작과 완료 조건을 정의합니다.
3. [화면 구성](03-screens.md): 사용자의 흐름과 화면을 설계합니다.
4. [작업 로드맵](04-roadmap.md): 작업 순서와 진행 상황을 관리합니다.
5. [의사결정 기록](05-decisions.md): 선택한 이유와 제약을 남깁니다.

## 운영 규칙

- 서비스 동작을 바꾸면 관련 기획과 코드를 함께 갱신합니다.
- 요구사항은 ID, 동작, 완료 조건, 상태를 남깁니다. 상태는 `예정`, `진행`, `완료`, `보류`를 사용합니다.
- 확정하지 않은 내용은 `미정`으로 표시합니다.
- 새 문서는 `06-feature-name.md`처럼 추가합니다. 첫 번째 `# 제목`이 사이트 문서 제목이 됩니다.
- 이 폴더의 최상위 `.md` 파일은 빌드할 때 사이트에 포함됩니다. 내부 정보와 개인 정보는 적지 않습니다.
- 기획 파일을 바꾼 뒤 main에 푸시하면 문서 화면도 자동 배포됩니다. 기능 구현이 필요한 요구사항은 `src/`도 함께 수정합니다.
