### 포함할 내용

- 음식점 쿠폰 신규 출처와 지역 조사, 실제 근거가 있는 후보 추가, 중복·출처·한영 매장명 관리.

- 변경별 검사·빌드·main 커밋·푸시·Pages 배포 확인과 작업 기록.
- 한 시간 간격의 후속 자율 개선, 종료 시 결과 보고. 실제 예약 실행 성공과 접근 가능 여부는 실행 시 확인한다.

### 제외할 내용

무근거 쿠폰·유효기간·외국인 사용 가능성 생성, 로그인·접근 제한 우회, 타인 연락, 결제·예약·대리 쿠폰 발급·유료서비스 등록.
