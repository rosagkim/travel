# 쿠폰 탐색 화면과 변경 시 자동 배포

상태: 구현 중

## 논의 배경

사용자가 사이트가 비어 있음을 지적하고 수정될 때마다 바로 배포되도록 요청했다. 기존 빈 HTML을 실제 쿠폰 탐색 화면으로 바꾼다. 기존 GitHub Pages 주소와 main 직접 배포 흐름을 유지한다.

## 목표와 범위

### 목표

사이트에 방문하면 실제 조사한 쿠폰을 탐색할 수 있고, main 수정 시 검사·빌드 후 최신 화면이 자동 배포되게 한다.

### 포함할 내용

- 모바일·데스크톱에서 지역·업종·검색어별 탐색, 상세 안내, 원본 쿠폰 및 매장 위치 링크.
- 영어·한국어 인터페이스. 쿠폰 원문과 검수 상태를 명확하게 표시한다.
- 조사 후보와 검수 완료 쿠폰을 분리하며 후보를 사용 가능으로 단정하지 않는다.
- main 푸시 자동 배포, 최신 변경 우선 처리, 빌드 식별자와 배포 결과 확인.

### 제외할 내용

- 로그인·결제·쿠폰 대리 발급·상시 수집. 미확인 상세 정보의 추정.

## 사용자 흐름

사이트 방문 → 지역·업종·검색어 선택 → 쿠폰 카드 선택 → 혜택 원문과 검수 상태·유효기간·조건 확인 → 네이버 원본 또는 매장 위치 열기. 검수 완료만 선택하면 현재 검수 완료 쿠폰이 없다는 안내를 제공한다.

## 완료 조건

- [x] 첫 화면이 비어 있지 않고 실제 데이터에 연결된다.
- [x] 검색·지역·업종·검수 필터, 초기화와 결과 없음 안내가 동작한다.
- [x] 상세 화면에서 미확인 항목과 원본·위치 링크를 제공한다.
- [x] 영어·한국어 전환과 모바일 대응, 키보드 접근을 지원한다.
- [x] 검사·빌드 및 빌드 산출물 검증을 통과한다.
- [ ] main 푸시 배포 성공과 실제 사이트의 새 HTML·자산 응답을 확인한다.

## 열린 질문

쿠폰별 상세 검수와 확정된 번역은 후속 작업으로 진행한다.

## 구현과 검증

- [화면](../../src/main.js), [반응형 스타일](../../src/style.css), [진입 HTML](../../index.html).
- [배포 구성](../../.github/workflows/deploy.yml)은 main 푸시를 검증·빌드·배포한다. `cancel-in-progress: true`로 최신 실행을 우선한다.
- [빌드 식별자](../../vite.config.js)로 배포 HTML을 커밋과 연결하고 [실사이트 검증](../../scripts/verify-deployment.mjs)에서 새 HTML·JS·CSS 응답을 자동 확인한다.
- `npm run check` 테스트 14개와 `npm run build`, `git diff --check` 통과. [화면 상호작용 테스트](../../scripts/ui.test.mjs)에서 지역·업종·검색·검수 필터, 초기화, 상세 창, 원본·위치 링크, 언어 전환과 저장소 비활성 환경을 확인했다.
- 반응형 CSS와 기본 키보드·다이얼로그 접근성을 구현했다. 연결된 브라우저 도구가 없어 실제 브라우저 시각·키보드 QA는 미실시이며 DOM 기반 기능 검증으로 한정한다.
- 실제 배포 확인 진행 중.
