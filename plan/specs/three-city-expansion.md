# 서울·부산·제주 쿠폰 탐색 확장

상태: 구현 중

## 논의 배경

사용자가 “서울, 부산, 제주 이렇게 외국인 많이 가는곳 3개 도시에 대해서 해줘”라고 요청했다. 서울 한 지역에 머물던 탐색 화면과 쿠폰 후보 데이터를 부산·제주로 확장한다.

## 목표와 범위

### 목표

서울·부산·제주를 선택해 각 지역의 실제 출처가 있는 음식점 쿠폰 후보를 탐색한다. 제주 선택 범위는 여행 목적지 제주도이며 제주시·서귀포시를 구분한다.

### 포함할 내용

- 네이버 공개 검색에서 부산·제주 매장별 쿠폰 요약·좌표·지역과 원본 링크를 확인해 저장.
- 출처 목록의 요약과 개별 쿠폰 상세 검증을 구분. 종료 기획전 혜택은 추가하지 않는다.
- 도시·지역·업종·검색 필터와 도시별 실제 건수, 영어·한국어 안내.
- 도시 전환 시 다른 도시의 동네 선택 초기화와 도시 경계 필터 검증.
- main 자동 배포 및 실제 사이트 새 HTML·자산 확인.

### 제외할 내용

로그인·쿠폰 대리 발급·접근 제한 우회·자동 수집. 출처에 없는 쿠폰 ID·상세 조건·유효기간의 생성.

## 사용자 흐름

전체 또는 도시 선택 → 해당 도시 지역·업종·검색어로 탐색 → 후보 상태·원문 요약 확인 → 원본 매장 쿠폰 안내·지도 열기. 도시 변경 시 지역 필터를 초기화하고 해당 도시 후보만 보여준다.

## 완료 조건

- [x] 부산·제주에 실제 출처·좌표·지역을 갖는 쿠폰 후보를 추가한다.
- [x] 개별 쿠폰 ID가 없는 검색 요약을 별도 증거 수준으로 저장하고 중복을 검사한다.
- [x] 도시 전환·지역 필터·검색·표시 건수가 실제 데이터와 일치한다.
- [x] 검수 전 상태와 상세 정보 미확인을 유지하고 종료 행사 혜택을 섞지 않는다.
- [ ] 관련 테스트·검사·빌드와 main 배포 후 실사이트 검증이 통과한다.
