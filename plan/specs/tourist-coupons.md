# 방한 외국인 관광객 쿠폰 앱

상태: 초안

## 논의 배경

사용자는 한국에 오는 외국인 관광객을 대상으로, 한국에서 사용할 수 있는 쿠폰을 모아서 제공하는 앱을 만들고자 한다.

## 목표와 범위

### 목표

방한 외국인 관광객에게 한국에서 사용할 수 있는 쿠폰을 모아 제공한다. 한국의 여러 서비스가 웹에서 제공하는 쿠폰 정보를 한곳에서 지역·업종별로 탐색하고, 혜택과 실제 사용에 필요한 정보를 확인할 수 있게 한다.

### 포함할 내용

- 대상 사용자: 한국을 방문하는 외국인 관광객.
- 핵심 방향: 한국에서 사용할 수 있는 쿠폰을 모아 제공하는 앱.
- 수집 대상: 한국의 어떤 서비스든 웹에서 제공하는 쿠폰 전반. 관광객 전용 쿠폰으로 한정하지 않는다.
- 수집 방향: 웹에 제공되는 쿠폰 정보를 폭넓게 수집·통합한다. 개별 수집처와 기술 방식, 첫 출시의 수집 범위는 추가로 정한다.
- 지역·업종별 쿠폰 탐색.
- 쿠폰별 할인 혜택, 유효기간, 사용 조건 확인.
- 사용 가능한 매장 위치와 쿠폰 사용 방법 안내.

### 제외할 내용

미정. 제휴, 결제, 예약, 쿠폰 발급 등의 포함 여부는 아직 결정하지 않았다.

## 사용자 흐름

1. 지역과 업종을 기준으로 쿠폰을 탐색한다.
2. 쿠폰의 할인 혜택, 유효기간, 사용 조건을 확인한다.
3. 사용 가능한 매장 위치와 사용 방법을 확인한다.
4. 안내된 절차에 따라 쿠폰을 사용한다. 원본 서비스로 이동하거나 쿠폰을 제시·발급받는 세부 방식은 수집처별 확인 후 정한다.

## 완료 조건

- [ ] 관광객 전용으로 제한하지 않은 웹 쿠폰 수집처와 초기 수집 범위가 정해져 있다.
- [ ] 지역·업종별로 해당 쿠폰을 탐색할 수 있다.
- [ ] 쿠폰별 할인 혜택, 유효기간, 사용 조건을 확인할 수 있다.
- [ ] 사용 가능한 매장 위치와 쿠폰 사용 방법을 확인할 수 있다.
- [ ] 출처별 실제 쿠폰을 기준으로 수집·안내 정보가 일치하는지 검증한다.

## 열린 질문

- 웹 쿠폰 수집을 시작할 서비스와 출처는 무엇이며, 수집·갱신 방식은 어떻게 정할 것인가?
- 사용자는 쿠폰을 어떻게 사용할 것인가? 외부 발급처 이동, 매장 제시, 앱 내 발급 등의 절차는 미정이다.
- 첫 출시에서 다룰 지역과 업종은 무엇인가?
- 처음 지원할 언어는 무엇인가?
- 앱의 제공 형태는 모바일 웹, 네이티브 앱 등 중 무엇인가?
- 유효기간, 사용 조건, 사용 가능 매장과 정보 갱신은 어떻게 관리할 것인가?
- 한국 전화번호, 본인 인증, 서비스 가입, 특정 결제수단 등 외국인 관광객의 사용 가능 여부에 영향을 주는 조건을 어떻게 확인·표시할 것인가? 이는 검토할 질문이며, 아직 별도 표시 기능으로 합의한 것은 아니다.
- 온라인 전용·전국 공통 쿠폰은 지역 및 매장 위치 탐색에서 어떻게 다룰 것인가?
- 쿠폰 원문이 불명확하거나 유효기간·매장 정보가 없는 경우 어떤 기준으로 안내할 것인가?
- 수익 모델과 로그인 필요 여부는 무엇인가?

## 구현과 검증

서비스 기능은 아직 구현하지 않았다. 범위와 사용자 흐름을 합의하기 전까지 사이트는 빈 화면을 유지한다.

## 변경 기록

- 2026-10-29: 사용자가 대상 사용자와 서비스의 핵심 방향을 제시했다. 해당 방향은 확인된 요구이며, 상세 범위와 사용자 흐름은 미정이므로 초안으로 유지한다.
- 2026-10-29: 사용자가 관광객 전용이 아닌 한국 서비스의 웹 쿠폰 전반을 수집 대상으로 명확히 했다. 지역·업종별 탐색, 할인 혜택·유효기간·사용 조건 확인, 사용 가능한 매장 위치·사용 방법 안내를 요구사항으로 반영했다. 초기 수집 범위와 기술·운영 방식은 미정이므로 초안 상태를 유지한다.
