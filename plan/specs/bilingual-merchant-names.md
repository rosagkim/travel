# 세 도시 매장명 한영 표시 통일

상태: 구현 중

## 논의 배경

사용자가 서울 매장명은 영어, 부산·제주는 한국어로 표시되는 문제를 지적했다. 이전 답변에서 한국어 원명과 영문명을 함께 표시하겠다고 설명했으나 실제 반영하지 않았고, 사용자가 수정을 요청했다.

## 목표와 범위

### 목표

수집처 언어와 무관하게 모든 매장명을 한국어·영어로 함께 표시하고 언어 선택에 따라 우선순위를 통일한다.

### 포함할 내용

- 서울 기존 매장 ID와 한국어 원문 응답을 대조해 한국어명을 확인한다.
- 52개 매장의 한영 이름을 매장 ID별로 관리하고 출처와 영문 표기 방식을 기록한다.
- 한국어 화면은 한국어명 우선, 영어 화면은 영문명 우선이며 두 이름 모두 카드·상세에 표시한다.
- 출처에서 확인한 영문명이 없으면 한국어 원명의 로마자 표기를 제공한다. 임의 의역하지 않으며 공식 영문명으로 주장하지 않는다.
- 두 언어와 원문명 검색, 검사·테스트·빌드·main 배포 확인.

### 제외할 내용

쿠폰 혜택 번역, 쿠폰 조건 검수 완료 처리, 모든 매장의 공식 영문명 인증.

## 사용자 흐름

매장 카드에서 한영 이름 확인 → 언어 전환 시 두 이름의 순서 변경 → 한국어·영문·수집 당시 원문 이름으로 검색 → 상세에서도 같은 한영 이름 확인.

## 완료 조건

- [x] 서울 17개 매장의 한국어 원명을 ID로 대조한다.
- [x] 52개 매장 모두 한영 이름과 출처·표기 방식을 갖는다.
- [x] 세 도시 카드·상세의 언어별 이름 순서가 같고 두 이름으로 검색된다.
- [x] 이름 누락·공백·출처 누락을 검사하고 관련 테스트와 빌드가 통과한다.
- [ ] main 배포 후 새 HTML·JS·CSS 응답을 확인한다.

## 열린 질문

로마자 표기를 매장 공식 영문명으로 대체하려면 해당 매장의 공식 표기를 추가 확인한다.
