# 요구사항

현재 기반의 완료 조건과 앞으로 추가할 기능의 작성 형식을 관리합니다.

## 기반 요구사항

| ID | 동작 | 완료 조건 | 상태 |
| --- | --- | --- | --- |
| PLAN-001 | 기획을 plan/에 정리한다 | 개요, 요구사항, 화면, 로드맵, 의사결정 문서가 있다 | 완료 |
| DOC-001 | 기획 문서를 사이트에 표시한다 | plan/*.md 수정과 새 문서 추가가 빌드 결과에 반영된다 | 완료 |
| DOC-002 | 문서를 검색한다 | 제목과 본문에서 검색하고 결과 문서로 이동한다 | 완료 |
| SITE-001 | 작은 화면에서도 읽을 수 있다 | 모바일 메뉴, 문서 표 가로 스크롤, 키보드 탐색을 지원한다 | 완료 |
| DEPLOY-001 | main 변경을 자동 배포한다 | main 푸시 후 검증·빌드한 결과를 Actions 아티팩트로 전달해 Pages에 직접 배포한다 | 완료 |
| DEPLOY-002 | main 하나로 운영한다 | 소스와 기획을 main에서 관리하고 빌드 결과용 브랜치와 별도 게시 스크립트를 사용하지 않는다 | 완료 |

main 푸시로 시작한 GitHub Actions 검증·빌드·직접 배포가 성공했습니다. 공개 사이트와 빌드된 JavaScript·CSS가 HTTP 200으로 응답하고 로컬 빌드 결과와 일치하는 것을 확인했습니다.
