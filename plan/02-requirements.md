# 요구사항

현재 기반의 완료 조건과 앞으로 추가할 기능의 작성 형식을 관리합니다.

## 기반 요구사항

| ID | 동작 | 완료 조건 | 상태 |
| --- | --- | --- | --- |
| PLAN-001 | 기획을 plan/에 정리한다 | 개요, 요구사항, 화면, 로드맵, 의사결정 문서가 있다 | 완료 |
| DOC-001 | 기획 문서를 사이트에 표시한다 | plan/*.md 수정과 새 문서 추가가 빌드 결과에 반영된다 | 완료 |
| DOC-002 | 문서를 검색한다 | 제목과 본문에서 검색하고 결과 문서로 이동한다 | 완료 |
| SITE-001 | 작은 화면에서도 읽을 수 있다 | 모바일 메뉴, 문서 표 가로 스크롤, 키보드 탐색을 지원한다 | 완료 |
| DEPLOY-001 | main 변경을 자동 배포한다 | 검증·빌드 후 github-pages에 결과물을 푸시하고 Pages에 배포한다 | 완료 |
| DEPLOY-002 | 빌드 결과를 직접 배포한다 | npm run deploy로 github-pages를 갱신하면 브랜치 워크플로가 배포한다 | 완료 |
