# 서비스 개요

서비스가 해결할 문제와 첫 번째 사용자를 정의하는 시작 문서입니다.

## 서비스 정의

| 항목 | 내용 |
| --- | --- |
| 서비스 이름 | 미정 — 현재 사이트의 임시 이름은 서비스 베이스 |
| 한 줄 소개 | 미정 |
| 핵심 사용자 | 미정 |
| 해결하려는 문제 | 미정 |
| 사용자에게 제공할 가치 | 미정 |
| 성공을 판단할 지표 | 미정 |

## 첫 버전 범위

### 준비한 기반

- 기획을 마크다운으로 작성하고 사이트에서 읽을 수 있는 구조
- 데스크톱과 모바일을 지원하는 기본 화면
- main 푸시부터 GitHub Pages 배포까지 이어지는 자동화

### 서비스 기획 후 정할 항목

- 사용자가 가장 먼저 해야 하는 행동 한 가지
- 첫 버전에 꼭 필요한 기능 1~3개
- 완료 여부를 확인할 수 있는 사용자 시나리오
