# 화면 구성

현재 기본 사이트의 화면과 서비스 화면을 확장할 위치를 정의합니다.

## 전체 구조

| 화면 | 주소 | 역할 |
| --- | --- | --- |
| 시작 화면 | #/ | 기획 문서와 작업 흐름의 진입점 |
| 기획 문서 | #/plan/파일이름 | 마크다운 문서 본문과 이전·다음 탐색 |
| 작업 로드맵 | #/plan/04-roadmap | 단계별 할 일과 완료 상황 |

## 공통 영역

- 왼쪽 메뉴: 시작 화면, 기획 문서, 작업 로드맵, GitHub 저장소
- 상단: 문서 검색과 현재 위치
- 작은 화면: 메뉴 열기·닫기 버튼과 배경 오버레이
- 본문: 키보드 포커스, 읽기 쉬운 제목 계층, 표 가로 스크롤

## 문서 화면

- plan/ 최상위의 마크다운 파일을 파일명 순서대로 정렬합니다.
- 첫 번째 `# 제목`을 메뉴와 페이지 제목에 사용합니다.
- 문서 사이의 상대 `.md` 링크는 사이트 내부 이동으로 연결합니다.
- 알 수 없는 문서 주소는 안내 화면을 표시합니다.
- 원본 문서를 GitHub에서 열 수 있습니다.

## 서비스 화면 확장

구체적인 서비스가 정해지면 핵심 사용자 행동, 필요한 입력, 결과, 오류 처리, 모바일 배치를 이 문서에 추가하고 `src/`에서 구현합니다.
