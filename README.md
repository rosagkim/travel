# 서비스 기획과 개발

한국을 방문하는 외국인 관광객을 위해 서울·부산·제주의 음식점 쿠폰을 모아 제공하는 앱입니다. 지역·업종별 쿠폰 탐색 화면을 제공하며, 검수 전 후보는 미확인 상태를 표시합니다. [기획 시작 문서](plan/README.md)에서 현재 맥락을 읽고 대화를 이어갑니다.

## 기획 관리

Node.js 24에서 `npm ci` 후 사용합니다. 별도 문서 서비스나 데이터베이스 없이 마크다운과 Git으로 관리합니다.

```sh
npm run plan:new -- feature-name "논의 주제"  # 템플릿으로 초안 생성
npm run plan:list                            # 기획 목록과 상태
npm run plan:check                           # 상태·필수 항목·파일 링크 검사
```

기획은 `plan/specs/`에 필요할 때만 만듭니다. 합의한 결정과 그 이유는 [합의 기록](plan/decisions.md)에 저장합니다. 파일 작성만으로 합의한 것으로 처리하지 않습니다. 기획 문서는 사이트에 표시되지 않습니다.

## 개발과 배포

```sh
npm run dev      # 쿠폰 탐색 사이트 로컬 실행
npm run check    # 기획 문서와 관리 도구 검증
npm run build    # 정적 사이트 빌드
```

사용자 화면은 `src/main.js`, 스타일은 `src/style.css`에 있습니다. `main`에 커밋·푸시하면 GitHub Actions가 검증·빌드 후 Pages에 직접 배포합니다. 별도 배포 브랜치는 사용하지 않습니다.

사이트: https://rosagkim.github.io/travel/

## 쿠폰 데이터 초기 세팅

네이버 음식점 조사로 3개 여행 목적지, 92개 매장의 쿠폰 후보 98건을 저장했습니다(서울 50건·부산 26건·제주 22건). 현재는 상세 조건 검수 전이며 공개 가능한 쿠폰은 0건입니다. 조사·출처·접근 한계는 [조사 기록](plan/research/naver-food-2026-10-29.md), 데이터 구조와 검수 방법은 [데이터 안내](data/coupons/README.md)에 있습니다.

`npm run coupons:check`로 후보 데이터와 공개 가능 건수를 검사합니다. `npm run check`에는 쿠폰 데이터 검사와 관련 테스트도 포함됩니다. 초기 지역·업종·검수 정책은 `config/coupon-bootstrap.json`에 저장하며 자동 수집은 비활성화 상태입니다.

화면에서 후보를 탐색할 수 있으며, ‘검수 완료만 보기’는 공개 가능 검사를 통과한 쿠폰만 보여줍니다. `main` 푸시마다 검증·빌드·배포하며 연속 수정 시 최신 실행을 우선합니다.

[3개 도시 확장 조사](plan/research/three-city-2026-10-29.md)에서 부산·제주 후보 출처를 확인할 수 있습니다. 도시 선택 시 해당 지역과 후보만 표시하며, 사용자 화면은 Korea Perks로 표기합니다.

매장명은 서울·부산·제주 모두 한국어와 영문을 함께 표시합니다. 화면 언어에 따라 우선순위가 바뀌며, 한국어·영문·수집 원문 이름으로 검색할 수 있습니다. 영문명이 출처에서 확인되지 않은 매장은 로마자로 표기합니다.

영어 혜택 요약, 혜택 유형·원문 조건 필터와 이 기기의 저장 목록을 제공합니다. 추가 할인 제공처 안내는 개별 음식점 쿠폰 수에 포함하지 않습니다. [2026-10-30 자율 개선 기록](plan/specs/traveler-improvement-window.md)에 진행 상황을 남깁니다.

제주 선결제 할인 상품 6개(탐나오 가격 옵션 9개)는 매장 쿠폰 후보 수와 분리해 정상가·판매가·절약액·구매 후 사용 기한과 조건을 표시합니다. 가격은 확인 시점 기준이며 구매 가능성·외국인 결제는 미확인입니다. 상세에서 한국어 이름과 혜택 링크를 복사하고 네이버 지도로 이동할 수 있습니다.

‘내 위치로 가까운 순’ 버튼을 누르면 브라우저 위치 권한을 요청해 매장 후보를 직선거리로 정렬합니다. 방문자 위치는 현재 페이지 메모리에서만 사용하고 저장·서버 전송하지 않으며, 위치 해제나 권한 거부 시 수동 필터로 탐색할 수 있습니다. 표시 거리는 도보 경로나 이동 시간이 아닙니다.
