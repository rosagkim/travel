# 서비스 개발 작업 기반

아직 만들 서비스는 정하지 않았습니다. 현재 사이트는 빈 화면이며, 함께 기획한 뒤 구현합니다.

- `plan/`: 대화에서 합의한 기획을 마크다운으로 기록합니다. 사이트에 자동 공개하지 않습니다.
- `src/`: 확정한 화면과 기능을 구현합니다. 현재는 비어 있습니다.
- `main`에 푸시하면 GitHub Actions가 검증·빌드 후 GitHub Pages에 직접 배포합니다.

## 실행

Node.js 24에서 `npm ci`, `npm run dev`를 실행합니다.
검증은 `npm run check`, 빌드는 `npm run build`입니다.

## 함께 작업하는 순서

1. 아이디어와 해결할 문제를 함께 논의합니다.
2. 합의한 범위만 plan/에 기록합니다.
3. 요구사항과 화면을 구체화한 뒤 구현합니다.
4. 검증한 변경을 main에 커밋·푸시해 배포합니다.
